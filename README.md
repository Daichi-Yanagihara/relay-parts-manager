# Relay Parts Manager

電力保護リレー装置の機種・ユニット・用品情報を一元管理するWebアプリケーションです。

## プロジェクト概要

本システムは、電力インフラ設備で使用される保護リレー装置を対象とした、用品管理・設計支援システムです。

機種、ユニット、用品の情報をデータベースで一元管理し、用品の検索や構成情報の確認、使用数量の管理などを効率的に行うことを目的としています。

電力インフラ関連のハードウェア設計業務で得た知識や経験を基に、Webアプリケーションとして企画・設計しています。

※本システムは個人開発のポートフォリオ作品です。実際の企業・設備に関する機密情報は使用せず、架空の機種・ユニット・用品データを利用します。

## 開発背景

電力保護リレー装置の設計業務では、機種ごとに複数のユニットが存在し、各ユニットには基板、ケーブル、電子部品などの用品が使用されます。

これらの情報がExcelや複数の設計資料に分散している場合、次のような課題が発生すると考えました。

- 必要な用品情報を探すのに時間がかかる
- ユニットごとの構成用品や使用数量を確認しにくい
- 特定の用品がどのユニットで使用されているか把握しにくい
- 仕様やメーカーの変更時に、関連情報の確認に手間がかかる
- 過去に使用した用品情報を再利用しにくい

これらの課題を解決するため、機種・ユニット・用品の関連情報を一元管理できるWebシステムを開発します。

## 主な機能

### ユーザー認証
- ログイン・ログアウト
- ログイン状態の確認
- 未認証ユーザーのアクセス制限

### 機種管理
- 機種情報の一覧表示
- 機種の新規登録・詳細表示・編集・削除
- 機種コード・機種名・用途などによる検索
- 機種に関連するユニットの確認

### ユニット管理
- ユニット情報の一覧表示
- ユニットの新規登録・詳細表示・編集・削除
- ユニット名・型式・種別・所属機種などによる検索
- ユニットの仕様情報の管理
- 所属機種との関連付け

### 用品管理
- 用品情報の一覧表示
- 用品の新規登録・詳細表示・編集・削除
- 用品コード・用品名・型番・分類・メーカーなどによる検索
- メーカー・仕様・リードタイム（LT）の管理
- 用品の使用先ユニットの逆引き検索

### 用品構成管理
- ユニットごとの構成用品一覧表示
- 構成用品の追加・関連付け解除
- 使用数量の登録・変更

### その他
- 一覧画面のページネーション
- 表示件数の切り替え
- 入力値チェック・エラー処理

## データベース設計

主に以下のテーブルを使用します。

| テーブル名 | 管理内容 |
|---|---|
| profiles | ユーザー情報 |
| models | 機種情報 |
| units | ユニット情報 |
| parts | 用品情報 |
| model_units | 機種とユニットの関連情報・使用数量 |
| unit_parts | ユニットと用品の関連情報・使用数量 |

### テーブル間の関係

- 機種とユニット：多対多（model_unitsで管理）
- ユニットと用品：多対多（unit_partsで管理）
- ユーザー認証：Supabase Authを使用

## 工夫した点・こだわり

### 実務経験を活かしたシステム設計

電力保護リレー装置のハードウェア設計に関する業務経験を基に、実際の設計業務で扱う機種・ユニット・用品の関係性を意識して設計しています。

### 用品の使用先を逆引きできる構成

通常の用品検索だけでなく、特定の用品がどのユニットに使用されているか確認できる機能を設計しています。

### 多対多のデータ構造

機種とユニット、ユニットと用品の関連付けを中間テーブルで管理し、複数の機種やユニットで共通の情報を再利用できる構成にしています。

### 情報を探しやすい画面設計

一覧・詳細・登録編集の画面を分け、検索条件や表示件数を指定できるシンプルなUIを目指しています。
